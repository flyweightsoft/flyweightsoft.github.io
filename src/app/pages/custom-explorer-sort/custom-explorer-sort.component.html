Free · Open Source VS Code Extension

Custom Explorer Sort

Sort files and folders in VS Code's Explorer using a simple .order file. Respects .gitignore, adjusts mtimes safely, and provides full control over workspace organization.

Install from Marketplace GitHub

Features

  • ✓
    Custom ordering via .order file — one filename per line
  • ✓
    Advanced matching glob pattern and regex support for flexible matching
  • ✓
    .gitignore integration ignored files are excluded automatically
  • ✓
    Stable mtime-based sorting safe adjustments, no file corruption
  • ✓
    Recursive support works flawlessly for nested directories
  • ✓
    Lightweight zero runtime dependencies

Example .order file

README.md src docs (regex)**/*.test.ts (regex)*.json

Files listed first appear at the top. Unlisted files fall to the bottom in their default order.

1

3
